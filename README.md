# Clinica Medicare – Healthcare Website

A professional healthcare website developed for **Clinica Medicare**, designed to establish a strong digital presence and provide visitors with easy access to clinic information, healthcare services, and patient engagement features.

### Project Overview

The website provides a responsive and user-friendly platform for showcasing the clinic's services, medical specialists, treatment information, and healthcare facilities.

### Key Features

- Responsive and modern healthcare website.
- Dedicated pages for clinic information and medical specialties.
- Doctor profiles and treatment information.
- Appointment enquiry functionality.
- Interactive hair assessment system.
- Patient photo upload functionality.
- Admin authentication interface.
- Healthcare gallery and patient testimonials.
- WhatsApp integration for communication.
- Search engine optimization (SEO) metadata.

### Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **CSS Framework:** Bootstrap 5
- **Backend Services:** Supabase
- **Database & Storage:** Supabase services
- **Icons & UI:** Bootstrap Icons, Font Awesome
- **Animations:** AOS, Swiper
